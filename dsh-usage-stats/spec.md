# 使用统计插件

仅参考 ZCode 官方仓库的使用统计界面，不使用 dsh-scope 或第三方仿 ZCode 插件代码。

目标宿主：本机 DeepSeek Harness Desktop 0.2.2-rc.1。入口为设置菜单中的「使用统计」。
布局：五项累计摘要、52 周活动网格（每日/每周/累计）、近 7 日/30 日趋势、模型占比。
配色跟随宿主浅色/深色主题；窄设置面板内重排摘要，热力图始终完整展示。

宿主通过 sessionPersistence.list/open/read 的只读接口读取记录，排除分叉继承前缀，按完成 assistant/message 的 usage 计数。同一会话同一 seq 只计一次；统计使用提供方报告的 totalTokens，缺失则求四个互斥 Token 桶之和。没有 usage 的消息不估算。
模型按 provider/model 区分。时间以主机本地日历划分，返回明确时区。近 7/30 日包含今天；无活动日期补零。连续天数可延续到昨天；最长聊天时长为单会话本身事件的首末时间跨度，包含等待，不等于模型生成耗时。
所有累计数据来自当前 DSH_HOME 已保存的会话用量摘要；归档和删除后仍保留，重启和重复刷新不重计。归档管理清除日志前必须先成功保存最终用量；不查询账户余额、不添加个人套餐页、不上传数据。
后端仅开放同源、回环、带自定义请求头的 GET；拒绝跨站 Origin/Fetch Metadata。不修改 DSH 的 app.asar。

验收：聚合去重、分叉排除、跨日、坏日志提示、空数据、日期范围、热力图模式、主题与窄屏、设置 slot 注册和卸载、实际 0.2.2-rc.1 隔离 profile 加载。验证使用隔离 profile；日常 desktop 已通过目录链接安装，源码更新需构建后重新打开宿主。
